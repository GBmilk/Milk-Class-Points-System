# 牛奶智慧班级积分系统

> 一款面向小学/初中/高中班级日常管理的 Windows 桌面应用：学生积分、小组竞赛、积分商店、幸运大转盘、班级荣誉墙，全部数据保存在本机，离线可用，无需任何后端服务。

---

## 一、项目简介

「牛奶智慧班级积分」是一款纯前端、完全离线的班级积分管理桌面应用。教师（班主任）可以用它来：

- 管理学生信息，按拼音自动排序，男女分色卡片展示；
- 对学生进行加减分、批量加减分、小组加减分；
- 记录每一次积分变动的明细（加分/减分/购买/其他）；
- 开设「积分商店」，上架商品、打折、补货、下架，学生可用积分兑换；
- 组织「幸运大转盘」抽奖活动，奖品可关联商店商品；
- 建立学习小组，指定组长，实时统计小组总积分与排名；
- 维护班级荣誉墙，上传奖状图片，记录班级高光时刻；
- 查看个人/小组排行榜（前三名领奖台特效）与统计图表；
- 一键导入/导出全部班级数据（JSON），方便备份与迁移。

应用不需要联网、不需要安装数据库、不需要任何云端服务，所有数据（学生、积分、商品、小组、荣誉、设置）都保存在本机。

### 幸运大转盘使用说明

- 侧边栏「幸运大转盘」是**独立功能页**，页面默认**只显示转盘与中间的开始按钮**，方便课堂投屏时画面干净；转盘在内容区水平居中，并会随窗口高度自动缩放（1280×720 也能完整显示）；
- **「参与抽奖的学生」选择区就在转盘下方**：支持搜索选择，也可以点学生胶囊快速切换，并实时显示该生当前积分与本次抽奖的消耗提示；
- 点击右上角「抽奖设置」抽屉，可配置：**免费抽奖 / 消耗积分**（可设置每次消耗分数）、奖项与中奖概率；
- 奖项来源：**积分商店中「上架中」的商品**会自动成为奖项（可调权重、可设置中奖后是否扣 1 件库存），也可添加**自定义奖项**并命名；
- 权重为 0 的奖项不会出现在转盘上；缺货商品在抽奖前会被自动排除；商品上架/下架/改名/补货后转盘会自动同步；
- 转盘为真实旋转动画（约 4.2 秒），动画结束后统一结算：**扣积分 → 扣库存 → 写入中奖记录**，任一步校验失败则全部不落地，保证数据一致；
- 抽奖过程中按钮会被锁定，防止连续快速点击造成重复抽奖。

## 三、技术栈

- **桌面框架**：Electron 44（Chromium + Node.js 运行时）
- **构建工具**：electron-vite 5 + Vite 7
- **前端框架**：Vue 3.5（Composition API）+ TypeScript 5.9
- **状态管理**：Pinia 4
- **路由**：Vue Router 5
- **UI 组件库**：Element Plus 2.14 + @element-plus/icons-vue
- **数据可视化**：ECharts 6 + vue-echarts
- **中文拼音排序**：pinyin-pro
- **打包**：electron-builder 26（NSIS 安装包）
- **存储**：IndexedDB（主）+ localStorage（兜底），无任何后端/数据库

## 十、数据存储说明

- 业务数据保存在 **IndexedDB**（数据库 `milk-class-points-db`，key-value 结构），IndexedDB 不可用时自动**降级到 localStorage**，保证数据不丢失。
- 存储内容：系统设置、学生、积分记录、商品、小组、荣誉，以及数据结构版本号。
- 数据结构带 `dataVersion`，应用启动时自动做版本兼容升级与旧数据规范化。
- 应用重启、刷新后数据不会丢失；卸载应用前请先在「系统设置 → 数据管理」导出 JSON 备份。
- 所有数据仅存本机，不会上传到任何服务器。

## 十一、密码机制说明

1. 程序**没有账号**，只有密码。
2. 首次运行默认密码为 `123456`，仅用于首次初始化；登录界面、提示文字中不会显示该默认密码。
3. 普通登录密码使用 **SHA-256 / SHA-512 / SHA-1**（可在修改密码时选择算法）加随机盐哈希后存储，**绝不保存明文**。
4. 修改密码流程：输入旧密码 → 新密码（至少 6 位）→ 确认新密码，成功后立即更新本地存储，旧密码即刻失效。
5. 密码修改后的哈希保存在本机 IndexedDB/localStorage 中。

## 十二、pwd 管理员密码文件说明

- 管理员密码存放在一个名为 **`pwd`**（**无扩展名**）的文本文件中，文件内容就是管理员密码的明文文本。
- **普通密码**和**管理员密码**都可以打开程序：输入任意一个正确即可登录，登录身份分别显示为「普通」或「管理员」。
- 管理员密码只在 **Electron 主进程**中读取与校验（IPC 返回布尔结果），不会把明文传给渲染进程，也不会写入 localStorage。
- 文件查找顺序：
  1. 优先读取**可执行文件所在目录**下的 `pwd`；
  2. 若不存在，检查**应用数据目录**（`%APPDATA%\牛奶智慧班级积分`）下的 `pwd`；
  3. 写入时优先选择第一个可写目录，安装目录无写入权限时自动使用应用数据目录。
- 在「系统设置 → 管理员文件」页面可以：查看 `pwd` 文件**是否存在、实际路径、是否可写**，并可直接生成/更新该文件（不会回显明文内容）。
- **安全提醒：不要把 pwd 文件或其中的密码提交到公开代码仓库。**
- 若 `pwd` 文件不存在，程序不会崩溃，只是无法使用管理员密码登录。

### 如何修改管理员密码

1. 打开应用，进入「系统设置 → 管理员文件」；
2. 点击「生成 / 更新 pwd 文件」，输入新管理员密码并确认；
3. 程序会把密码写入实际可用的 `pwd` 文件（目录以页面显示为准）；
4. 退出登录后用新管理员密码即可登录。
5. 也可以手动用记事本编辑 `pwd` 文件（注意文件名不要带扩展名、内容为单行密码、UTF-8 编码），保存后重新登录生效。

## 十三、如何导入导出班级数据

- **导出**：进入「系统设置 → 数据管理 → 导出全部数据」，通过系统原生保存对话框选择位置，生成包含全部业务数据的 JSON 文件。
- **导入**：进入「系统设置 → 数据管理 → 导入全部数据」，通过原生文件选择框选择 JSON 文件；程序会先校验格式并显示数据摘要（学生数、记录数、商品数等），确认后**覆盖导入**。
- 导入失败（格式错误、结构不合法）不会破坏当前数据；危险操作均需多次确认。

## 十四、如何替换应用图标

- **应用/窗口图标**（任务栏、exe、安装包）：由 `build/icon.png`（PNG）与 `build/icon.ico` 决定。
- **界面内软件图标**（侧边栏 Logo、登录页 Logo）：由 `src/renderer/src/assets/milk-logo.png`（本地 PNG）决定；也可以在「系统设置 → 外观设置 → 软件图标」中直接选择本地 PNG 文件替换（小于 512KB，保留透明通道，重启后仍然生效，可一键恢复内置图标）。
- 使用仓库内脚本重新生成默认图标（含 PNG/ICO 与内置牛奶 Logo）：

```bash
npm run icon
```

- 自定义图标：替换 `build/icon.png`（建议 512×512 以上）和 `build/icon.ico`（建议多尺寸 16~256），再执行 `npm run icon` 可同步生成内置 Logo，最后重新执行 `npm run package`。
- 若图标文件不存在，开发环境启动不会失败（主进程做了存在性检查并使用备用方案）。
- 打包时会把 `build/icon.png` 与 `build/milk-logo.png` 复制到安装目录的 `resources/` 下，主进程按「开发环境读 build/、打包后读 resources/」的顺序查找本地 PNG 图标。

## 十五、常见问题

**Q1：Electron 安装失败 / 启动时提示找不到 electron 二进制？**
设置镜像后重新安装：`$env:ELECTRON_MIRROR='https://npmmirror.com/mirrors/electron/'; node node_modules/electron/install.js`

**Q2：`npm run package` 时 NSIS 工具链下载超时？**
国内网络可执行 `npm run package:mirror`（已配置 npmmirror 的 electron-builder 二进制镜像），或手动设置 `ELECTRON_BUILDER_BINARIES_MIRROR` 环境变量后重试。

**Q3：忘记普通密码怎么办？**
所有数据都存在本机 IndexedDB 中，如已开启管理员密码可用管理员密码登录；否则可备份数据后清除本机应用数据（IndexedDB/localStorage）恢复默认密码 `123456`。注意：清除数据前先导出 JSON 备份。

**Q4：安装目录没有写入权限，管理员密码文件写不进去？**
程序会自动改用应用数据目录（`%APPDATA%\牛奶智慧班级积分\pwd`），在「系统设置 → 管理员文件」中可以看到实际路径。

**Q5：自定义背景图重启后丢失？**
背景图会被压缩（限制大小）后持久化保存到本机数据中，重启后仍然生效；如需移除请点击「清除背景」。

**Q6：安装包体积较大（约 120 MB）？**
Electron 应用普遍如此，包含完整 Chromium 运行时；绿色版 `dist/win-unpacked` 可直接拷贝使用。

## 十六、安全注意事项

- 渲染进程开启 `contextIsolation`、禁用 `nodeIntegration`，通过 preload 的 contextBridge 仅暴露白名单 API。
- 渲染进程不能直接访问 Node.js 的 `fs` / `path` / `process` 等能力，文件读写、导入导出均走主进程原生对话框。
- IPC 通道数量有限、命名清晰，主进程对入参做基本校验。
- 不使用 `eval`，不加载远程网页，不依赖 CDN，完全离线可用。
- 普通登录密码不保存明文；管理员密码明文只在主进程内存中校验，不传给渲染进程。
- 图片上传限制大小与格式，避免异常文件导致崩溃；所有危险操作（删除/清空/重置/导入覆盖）均需二次确认。
